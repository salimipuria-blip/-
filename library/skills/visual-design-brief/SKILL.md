# visual-design-brief

## هدف
تبدیل یک خواستهٔ مبهم طراحی («یه چیز خوب بساز») به بریف دقیق قابل‌اجرا، یا ارزیابی یک طرح موجود بر اساس معیارهای مشخص — بدون نیاز به این‌که کاربر خودش زبان طراحی بلد باشد.

## چه زمانی فعال شود
وقتی کاربر دربارهٔ لوگو، هویت بصری، بنر، پست گرافیکی، بسته‌بندی، یا نظرخواهی/بازبینی یک طرح صحبت می‌کند.

## گردش کار
1. **مخاطب و پیام**: طرح قرار است چه چیزی را به چه کسی منتقل کند؟ (یک جمله)
2. **محدودیت‌های فنی**: رسانهٔ نهایی (چاپ/دیجیتال)، ابعاد، و هرگونه محدودیت برند موجود (رنگ/فونت ثابت) را مشخص کن.
3. **جهت بصری**: سبک مرجع (مینیمال/پرانرژی/سنتی/مدرن)، پالت رنگ پیشنهادی، و تایپوگرافی (برای متن فارسی، فونت خوانا و بدون مشکل نیم‌فاصله).
4. **سلسله‌مراتب بصری**: مشخص کن چشم بیننده اول کجا برود، بعد کجا — یک نقطهٔ کانونی، نه رقابت چند عنصر.
5. **اگر ارزیابی طرح موجود است**: نقاط قوت را اول بگو، بعد مشکلات را با دلیل مشخص (نه سلیقه‌ای) و راه‌حل عملی مطرح کن.

## چک‌لیست کیفیت
- [ ] پیام اصلی طرح در ۳ ثانیهٔ اول قابل‌درک است
- [ ] کنتراست رنگ و خوانایی متن فارسی رعایت شده (نیم‌فاصله، جهت راست‌چین)
- [ ] یک نقطهٔ کانونی روشن دارد، نه شلوغی رقابتی
- [ ] با محدودیت‌های برند (در صورت وجود) هم‌خوان است
- [ ] برای رسانهٔ نهایی (چاپ/موبایل/وب) بهینه است

## خروجی
بریف طراحی آماده (مخاطب/پیام/سبک/رنگ/فونت/ابعاد) یا گزارش ارزیابی طرح (نقاط قوت + مشکلات مشخص + پیشنهاد اصلاح).
