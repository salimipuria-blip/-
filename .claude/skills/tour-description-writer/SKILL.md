# Tour Description Writer — متن فراخوان تور

## ساختار فراخوان استاندارد (همیشه همین ترتیب)
1. **قلاب تجربی (۲–۳ خط)** — حس کردن سفر قبل از خواندن جزئیات.
2. **در یک نگاه (جدول):**
   | مقصد | تاریخ (شمسی) | مدت | حمل‌ونقل | شروع/پایان | سطح سختی | ظرفیت | قیمت (تومان) |
3. **برنامهٔ خلاصهٔ روزانه** — هر روز ۱–۲ خط (نه رمان).
4. **شامل / شامل نمی‌شود** — دو ستون، صریح و بی‌تعارف.
5. **با خودت بیار** — ۵–۸ قلم کلیدی (نه لیست کامل؛ به `packing-list-by-season` ارجاع بده).
6. **قوانین مهم** — سیاست کنسلی با درصدهای روشن + تعداد نفر حداقل+حداکثر + بیمه و مجوز.
7. **سؤال‌های پرتکرار (۳تا)** — واقعی، کوتاه، پاسخ شفاف.
8. **CTA** — یک مسیر پرداخت/رزرو + ددلاین.

## ادبیات
- «شما» محور و احساس‌بخش، ولی هر ادعای محسوس با واقعیت پشتوانه داشته باشد (مسافت کیلومتری واقعی، عکس واقعی).
- ممنوع: اغراق بی‌سند، «فراموش‌نشدنی» بدون دلیل، قیمت مبهم («تماس بگیرید» مگر عمدی).
- نیم‌فاصله و قیمت تومان با جداکننده هزار.

## خروجی (سه نسخه)
1. **نسخهٔ کامل** برای وبسایت/کانال (با ساختار بالا)
2. **نسخهٔ اینستا** (کپشن ≤ ۲۲۰۰ کاراکتر با قلاب و اشاره به «جزئیات در بیو/هایلایت»)
3. **نسخهٔ استوری** (۳ قاب: قلاب+قیمت+تاریخ, نکته منحصر, CTA با لینک)
+ جدول «می‌توانید این جاها شخصی‌سازی کنید» (تاریخ، ظرفیت، قیمت)
