# camp-recipe-posts

🗂 دسته: **تولید محتوا**
🎯 هدف این مهارت: دستور غذای سفر (گرم/سریع/اقتصادی)

## چه زمانی فعال شود
وقتی کاربر درخواستی مرتبط با «دستور غذای سفر (گرم/سریع/اقتصادی)» در حوزهٔ تولید محتوا بدهد؛ حتی اگر صریحاً نام مهارت را نگوید.
## گردش کار
1. مخاطب، هدف محتوا و کانال انتشار را قفل کن.
2. ساختار بنویس: قلاب → بدنهٔ ارزش‌محور → CTA.
3. متن را فارسی، طبیعی و بدون الگوهای AI تولید کن (جمله‌های متنوع، مثال واقعی).
4. ویرایش: حذف حشو/کلیشه، نیم‌فاصله، راستی‌آزمایی ادعاها.
5. قالب‌بندی برای کانال (کپشن/مقاله/اسکریپت) + عنوان‌های جایگزین.

## چک‌لیست کیفیت
- [ ] جملهٔ اول توقف‌کننده است
- [ ] ادعاها قابل استناد یا به‌صورت تجربی نشانه‌گذاری شده‌اند
- [ ] لحن برند و مخاطب حفظ شده
- [ ] تاریخ/عدد/واحد فارسی صحیح است (تومان، شمسی)
- [ ] CTA واضح و قابل اندازه‌گیری است

## خروجی
متن نهایی آمادهٔ انتشار + ۲-۳ تیتر/قلاب جایگزین.
