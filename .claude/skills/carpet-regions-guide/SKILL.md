# carpet-regions-guide

🗂 دسته: **اطلاعات ایران (Iran Knowledge)**
🎯 هدف این مهارت: فرش مناطق: تبریز/کاشان/قم

## چه زمانی فعال شود
وقتی کاربر درخواستی مرتبط با «فرش مناطق: تبریز/کاشان/قم» در حوزهٔ اطلاعات ایران (Iran Knowledge) بدهد؛ حتی اگر صریحاً نام مهارت را نگوید.
## گردش کار
1. دادهٔ محلی را از منبع معتبر بگیر؛ تاریخ به‌روزرسانی را بنویس.
2. یکان‌سازی: تاریخ شمسی، اعداد فارسی، ریال/تومان، نیم‌فاصله.
3. اگر قاعده/قوانین است: کلیات را بگو و مرجع رسمی و «به‌روز کن» را پیشنهاد بده.
4. خروجی را برای کاربر فارسی‌زبان نهایی کن (RTL، مثال واقعی).
5. ابهام/اختلاف منابع را شفاف اعلام کن.

## چک‌لیست کیفیت
- [ ] اعداد/فرمت‌ها فارسی و درست‌اند
- [ ] منابع معتبر/رسمی ذکر شده‌اند
- [ ] دادهٔ حساس به‌روز بودن مشخص است
- [ ] متن فارسی روان و فاقد ترجمهٔ ماشینی تحت‌اللفظی است
- [ ] احتیاط در موضوعات حقوقی/پزشکی با ارجاع به متخصص

## خروجی
اطلاعات آمادهٔ استفاده + منبع + یادآوری اعتبار زمانی داده.
