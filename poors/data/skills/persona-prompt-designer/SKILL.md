# persona-prompt-designer

🗂 دسته: **دقیق‌فهمیدن پرامپت (تجزیه و بهینه‌سازی پرامپت)**
🎯 هدف این مهارت: طراحی نقش/شخصیت مدل

## چه زمانی فعال شود
وقتی کاربر درخواستی مرتبط با «طراحی نقش/شخصیت مدل» در حوزهٔ دقیق‌فهمیدن پرامپت (تجزیه و بهینه‌سازی پرامپت) بدهد؛ حتی اگر صریحاً نام مهارت را نگوید.
## گردش کار
1. پرامپت را تجزیه کن: هدف/ورودی/خروجی/قیدها/مخاطب.
2. ابهام‌ها را فلگ کن و نسخهٔ بهبودیافته پیشنهاد بده.
3. ساختار استاندارد بده: نقش، زمینه، دستور، فرمت خروجی، مثال.
4. معیار آزمون تعریف کن و روی ۲-۳ ورودی نمونه تست بزن.
5. نسخه را ثبت کن (نام/تاریخ/تغییتر) و رژرسیون‌چک کن.

## چک‌لیست کیفیت
- [ ] خروجی موردانتظار Explicit است (فرمت/طول/لحن)
- [ ] مثال درست (و در صورت نیاز ضد‌مثال) آمده
- [ ] قیدهای منفی («چه نکن») روشن‌اند
- [ ] توکن/هزینه بهینه شده؛ حشو حذف شده
- [ ] نتیجهٔ تست و نمرهٔ کیفی مستند است

## خروجی
پرامپت بهینه + جدول تغییر و علت + نتایج تست.
