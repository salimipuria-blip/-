# desert-camp-playbook

🗂 دسته: **کمپ (Camp)**
🎯 هدف این مهارت: پلی‌بوک کویر: مرنجاب/شهداد

## چه زمانی فعال شود
وقتی کاربر درخواستی مرتبط با «پلی‌بوک کویر: مرنجاب/شهداد» در حوزهٔ کمپ (Camp) بدهد؛ حتی اگر صریحاً نام مهارت را نگوید.
## گردش کار (امنیت جلوتر از همه)
1. مشخصات گروه، فصل، منطقه و ظرفیت را قفل کن.
2. نقشهٔ اجرایی: چیدمان، تدارکات، آب، غذا، بهداشت، برق.
3. برنامهٔ گروه (زمان‌بندی روزانه) + مسئول هر بخش.
4. ریسک‌ها و پلن B: هوا، رود، حیات‌وحش، ارتباطات، امداد.
5. اسناد نفرات: لیست، رضایت‌نامه، تماس اضطراری، بیمه.

## چک‌لیست کیفیت
- [ ] چک‌لیست امنیت و کمک‌های اولیه کامل است
- [ ] اصل «ردی نگذار» (LNT) در برنامه دیده شده
- [ ] مجوزها/مناطق حفاظت‌شده بررسی شده
- [ ] برنامهٔ مدیریت زباله و آتش امن دارد
- [ ] هزینهٔ سرشکن شفاف محاسبه شده (تومان)

## خروجی
سند برنامهٔ اجرایی + چک‌لیست تجهیز/امنیت + برنامهٔ زمانی.
