# X Growth Analyzer

Turn analytics into a growth strategy.

## Diagnostic metrics
1. **Follow conversion** — follows / profile visits (<2% = weak positioning/bio/pinned post).
2. **Engagement rate** — by format & topic bucket; find top-decile patterns.
3. **Reply mix** — replies vs posts ratio; who's driving reach.
4. **Impression sources** — home feed vs profile vs search.
5. **Retention of followers** — churn signals after promo-heavy periods.

## Method
1. Parse export (CSV/screenshots) → per-post table.
2. Bucket posts: format, topic, hook type; compute medians per bucket (median, not mean).
3. Identify 3 repeatable winners and 3 underperformers with reasons.
4. Prescribe: content mix shift, posting cadence, engagement SOP, bio/pinned fixes.

## Output
Diagnosis report + do-more/do-less list + 4-week experiment plan with target metrics.
