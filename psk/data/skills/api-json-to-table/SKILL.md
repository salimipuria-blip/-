# api-json-to-table

🗂 دسته: **مرجع ورودی خارجی** — از لایهٔ عمومی جهان
🎯 هدف این مهارت: پاسخ API → جدول تمیز برای تحلیل

## چه زمانی فعال شود
وقتی کاربر درخواستی مرتبط با «پاسخ API → جدول تمیز برای تحلیل» بدهد؛ حتی بدون نام‌بردن مستقیم مهارت.
## گردش کار
1. «هدف» را یک‌جمله‌ای قفل کن: پاسخ API → جدول تمیز برای تحلیل
2. ورودی/زمینهٔ موجود را بخوان؛ در صورت نبود، نمونهٔ کوچک بساز.
3. مطابق قواعد دستهٔ «مرجع ورودی خارجی» اجرا کن و خروجی را آمادهٔ کپی تحویل بده.
4. فرض‌ها و محدودیت‌ها را صادقانه بنویس؛ مرحلهٔ بعدی را پیشنهاد بده.

## چک‌لیست کیفیت
- [ ] خروجی با هدف بخش اول هم‌خوان است
- [ ] استاندارد فارسی (نیم‌فاصله، تاریخ شمسی، تومان) رعایت شد
- فارسی/شمسی/تومان؛ خروجی آمادهٔ استفاده؛ فرض‌ها اعلام شود نه پنهان.

## خروجی
نتیجهٔ نهایی + چک‌لیست تأیید + پیشنهاد قدم بعدی.
