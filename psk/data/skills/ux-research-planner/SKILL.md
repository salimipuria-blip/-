# UX Research Planner

Turn a question into an executable study.

## Plan components
1. **Goals** — decision this research informs; 3-5 research questions (behavioral, not "would you like...").
2. **Method selection** — interviews / usability test (moderated vs unmoderated) / survey / diary / analytics + when each fits; mixed-method if stakes high.
3. **Participants** — screening criteria (behaviors over demographics), n per method (5-8 qualitative; surveys powered properly), recruitment channel, incentive.
4. **Instruments** — interview guide: warmup → context → tasks/past-behavior → probes ("tell me about the last time..."), no leading questions; usability tasks with success criteria; survey question bank with bias checks.
5. **Analysis plan** — affinity mapping process, tag taxonomy, how findings map to decisions, confidence caveat.
6. **Ops** — timeline, consent/NDA, tools, note-taker roles.

## Output
`research-plan.md` (all sections) + ready interview/task scripts + screening survey.
