# Deep Research

Rigorous multi-phase research with citations.

## Phases
1. **Scope** — restate the question precisely; list sub-questions; define what "done" looks like and what's out of scope.
2. **Plan queries** — 5-10 queries: broad landscape, specific claims, data/statistics, expert opinions, counter-arguments, recent updates (note current date).
3. **Gather** — read primary sources over aggregators; capture: claim, source, date, evidence type.
4. **Validate** — cross-check key claims across 2+ independent sources; rank source quality (primary > official > reputable press > blogs); flag single-source or stale claims.
5. **Synthesize** — structure findings by sub-question; consensus vs disputed points separated; quantify when possible.
6. **Gaps** — explicit "what we couldn't verify" section.

## Rules
- Every substantive claim carries a citation (URL + access date). No citation → mark as assumption.
- Prefer recent sources; note publication dates. Detect and disclose conflicts.
- Never invent statistics; quotes verbatim.

## Output
Research report: executive summary, findings per sub-question (cited), contested points, confidence levels, source list, open gaps, suggested next questions.
