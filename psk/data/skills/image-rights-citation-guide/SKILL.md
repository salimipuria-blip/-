# image-rights-citation-guide

🗂 دسته: **تولید و ساخت عکس**
🎯 هدف این مهارت: راهنمای ذکر منبع و حق نشر تصاویر

## چه زمانی فعال شود
وقتی کاربر درخواستی مرتبط با «راهنمای ذکر منبع و حق نشر تصاویر» در حوزهٔ تولید و ساخت عکس بدهد؛ حتی اگر صریحاً نام مهارت را نگوید.
## گردش کار
1. هدف تصویر، مخاطب و پلتفرم (سایز/نسبت) را مشخص کن.
2. کانسپت: سوژه، محیط، نور، سبک، حال‌وهوا — قبل از پرامپت.
3. پرامپت ساخت‌یافته بنویس: سوژه + فعل + محیط + قاب + نور + سبک + منفی‌ها.
4. تولید/ویرایش را انجام بده (با ابزار موجود)؛ در هر نسخه فقط یک متغیر را عوض کن.
5. خروجی را بابت متن داخل تصویر، دست‌ها، لوگو و وضوح بررسی کن.

## چک‌لیست کیفیت
- [ ] نسبت و سایز مطابق پلتفرم است (۱:۱، ۴:۵، ۹:۱۶ و...)
- [ ] متن فارسی داخل تصویر کوتاه و بدون غلط است
- [ ] سبک با برند هماهنگ است
- [ ] حق نشر/استفاده از چهره رعایت شده
- [ ] پرامپت نهایی همراه خروجی تحویل می‌شود

## خروجی
تصویر نهایی + پرامپت دقیق + ۲ تا ۳ واریانت پیشنهادی.
