# Brand Kit Generator

Create a consistent mini brand identity from a short brief.

## Workflow
1. **Strategy** — audience, positioning statement, 3 brand adjectives, competitor differentiation.
2. **Name & voice** — tone sliders (formal↔playful, bold↔calm), sample taglines, vocabulary do/don't list.
3. **Logo direction** — 2-3 conceptual directions described precisely (wordmark / monogram / abstract mark) + SVG draft of the strongest.
4. **Color** — palette with roles + contrast checks (see color-expert rules).
5. **Typography** — Google Fonts pairing (display + text) with usage hierarchy.
6. **Applications** — specify social avatar, banner, post template and simple one-page brand sheet.

## Output
`brand-kit.md` + assets (SVG logo draft, palette/tokens, type guide, templates).
