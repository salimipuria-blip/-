# Landing Page CRO

Find conversion leaks and rewrite the page to convert.

## Heuristic pass (LIFT)
1. **Value proposition** — is the #1 benefit clear in 5 seconds? Headline = outcome, not feature.
2. **Clarity** — jargon, vague claims, confusing flow; grade-level 6-8.
3. **Relevance** — message match between traffic source and page.
4. **Anxiety** — missing trust: reviews, numbers, guarantees, security, who-is-this.
5. **Distraction** — competing CTAs, leaking nav, carousels, excess fields.
6. **Urgency** — honest reasons to act now (never fake timers).

## Rewrite protocol
- Hero: headline + subhead + primary CTA + visual proof.
- Structure: problem → solution mechanism → benefits (outcome-worded) → proof → offer → objection FAQ → final CTA.
- Forms: min fields; multi-step if >3; label every microcopy.

## Output
Audit table (issue/impact/fix) + full rewritten page copy + 2-3 A/B test hypotheses with success metrics.
