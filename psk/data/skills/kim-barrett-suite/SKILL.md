# Kim Barrett Suite — Direct-Response Copy

Conversion-obsessed direct-response messaging.

## Toolkit
1. **Headlines** — formulas: "How to [result] without [pain]", "[Number] ways to...", "[Proof] in [timeframe]"; write 10, rank by specificity + curiosity.
2. **Big idea / hook** — one pattern-interrupt insight per campaign.
3. **Offer stack** — core promise + bonuses + guarantee + urgency + price anchor; make value math explicit.
4. **Objection handling** — list real objections (price, trust, time, fit) and answer each inside the copy with proof (data, testimonial, demo).
5. **Proof engine** — case study structure: before → obstacle → mechanism → result → specific numbers.
6. **CTA** — low-friction, outcome-worded ("Start recovering rankings" > "Submit").

## Rules
- Write at grade 6-8 reading level; one idea per sentence.
- Specific beats superlative: numbers, names, timeframes.
- Long copy ok if every line earns the next read.

## Output
Ready-to-run copy blocks per asset (headline set, offer, FAQ/objections, CTA) + rationale.
