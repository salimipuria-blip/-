# Reels Scripting

Reverse-engineer what works; rewrite in your voice.

## Reverse-engineering pass (for a reference viral reel)
Break down: hook frame + hook line (0-2s), retention device (open loop, movement, text), pacing (cuts per 5s), structure, payoff, CTA, caption, on-screen text style.

## Scripting structure
1. **Hook (0-2s)** — visual + spoken line: pattern interrupt, bold claim, or "you" callout.
2. **Setup (2-8s)** — context fast; promise the payoff.
3. **Body (8-45s)** — 2-4 beats; each beat = claim + proof/example; cut waste words; assume muted viewing → on-screen text mirrors speech.
4. **Payoff + CTA** — deliver the promise; single CTA (comment keyword / save / follow for part 2).

## Format output
Two-column script: | TIME | VISUAL/B-ROLL | SPOKEN LINE | ON-SCREEN TEXT |; plus caption + 3 title variants + cover frame suggestion.

## Rules
- 30-45s ideal; reading pace ~2.5 words/sec; script must be speakable (read aloud check).
- Adapt mechanics, not content: same psychology, your topic and voice.
