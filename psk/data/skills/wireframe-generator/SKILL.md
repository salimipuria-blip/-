# Wireframe Generator

Produce fast, annotated low-fidelity wireframes before visual design.

## Workflow
1. **Goal & flow** — user goal, primary CTA, required content per screen.
2. **Information hierarchy** — order sections by user priority; write the outline first.
3. **Render** — choose best medium:
   - ASCII wireframe for instant review in terminal/docs,
   - grayscale HTML/SVG (single hue + grays, no color) for shareable mockups.
4. **Conventions** — boxes for images (crossed), lines for text, labeled buttons `[Label]`, form fields with placeholders.
5. **Annotate** — number components; side notes: behavior, states, data source, edge cases.
6. **Variants** — propose 1-2 alternative layouts for the key screen.

## Rules
- Lo-fi only: no branding, icons or decorative styling — structure is the deliverable.
- Always include mobile + desktop variants.
- Mark above-the-fold line and expected interaction outcomes.

## Output
Wireframe(s) + annotation table (component, purpose, behavior, state) + open questions.
