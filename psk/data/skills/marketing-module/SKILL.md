# Marketing Module

Integrated growth execution: SEO, CRO, sales enablement and content automation.

## Modules (invoke per task)
1. **SEO** — technical checklist, on-page optimization, internal-link plan, schema markup.
2. **Growth** — channel strategy, funnel design, experiments backlog (ICE), reporting cadence.
3. **Sales** — ICP definition, cold outreach sequences, objection handling, demo scripts.
4. **CRO** — page audits (LIFT), A/B test specs, heatmap-informed fixes.
5. **Content automation** — briefs, calendars, repurposing pipelines, distribution checklists.

## Method
- Always anchor to a metric: traffic, conversion %, CAC, LTV, churn.
- Deliverables are execution-ready (copy written, checklist concrete, owner + deadline fields).

## Output
Per-module artifacts + a one-line metric target and review date.
