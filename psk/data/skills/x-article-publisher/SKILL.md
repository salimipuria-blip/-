# X Article Publisher

Adapt long-form articles for X — both the long-post format and thread versions.

## Workflow
1. **Core extraction** — boil article to its argument spine: thesis, 3-5 supporting moves, proof points.
2. **Long-post version (X Articles/long posts)** — hook first line (works standalone in the feed), short paragraphs, one idea each, headers for scanning, end with takeaway + CTA.
3. **Thread version** — post 1 = hook + promise; posts 2..N = one point each, numbered, self-contained enough to be quoted; final post = recap + link/CTA.
4. **Formatting** — line breaks for rhythm, minimal emojis, bold sparingly (X native), no hashtag stuffing (max 1-2, or none).
5. **Republish kit** — pull 3 quotable lines for future single posts; note best excerpt for LinkedIn adaptation.

## Output
Long-post text + thread text + quote bank, each within platform limits.
