# Prompt Optimizer

Turn vague prompts into reliable instructions.

## Method
1. **Diagnose** — find ambiguity, missing context, unstated format/criteria, conflicting constraints.
2. **Restructure** — role → task → context → constraints → output format → examples (if useful) → evaluation criteria.
3. **Right-size** — remove fluff; add only context that changes the answer.
4. **Variants** — provide a lean and a full version for high-stakes reuse.
5. **Test plan** — 3 test inputs + what a good output looks like.

## Output
Optimized prompt (lean + full) + a diff-style rationale of changes.
