# Canvas Design

Create professional-grade graphic design artifacts (posters, covers, social graphics) as polished SVG or self-contained HTML/CSS.

## Workflow
1. **Brief** — identify purpose, audience, format (dimensions), and brand constraints.
2. **Art direction** — pick 1-2 design references/styles (e.g. Swiss grid, brutalist, editorial, retro-futurist) and state the rationale.
3. **Composition** — define a clear grid, focal point and visual hierarchy before adding detail.
4. **Typography** — max 2 typefaces; establish scale (display/headline/body/caption), alignment and rhythm.
5. **Color** — 1 dominant + 1 accent + neutrals; ensure AA contrast for text.
6. **Build** — produce the artifact as layer-organized SVG or standalone HTML with inline CSS.
7. **Refine** — check spacing, alignment to grid, optical balance, and export at target resolution.

## Rules
- No default-looking outputs: avoid centered-everything layouts, generic gradients, system-font stacks.
- Every element must align to the grid; whitespace is a design element, not leftover space.
- Tailor aspect ratio to the platform (IG post 1:1, story 9:16, print A-series, etc.).

## Output
- The design file (preferred: SVG or single-file HTML) + a short rationale of style, palette and type choices.
