# Email Marketing

Full-system email: deliverability, segmentation, flows, copy.

## Deliverability
- SPF/DKIM/DMARC alignment, warming plan, list hygiene (sunset policy), spam-trigger audit.

## Segmentation
- RFM + behavior + engagement tiers (engaged 30/60/90d); per-segment cadence rules.

## Lifecycle flows (design + write)
1. Welcome (3-5 emails: value → story → offer)
2. Onboarding/activation
3. Abandoned cart/browse
4. Post-purchase & cross-sell
5. Win-back / re-engagement

## Copy rules
- Subject lines: 30-50 chars, curiosity or benefit (never both crammed); preview text complements.
- One idea + one CTA per email; scannable (short paragraphs, bullets).
- Plain-tone beats hype; personalize beyond first name (behavior references).

## Output
Flow map + fully written emails (subject, preview, body, CTA) + segmentation + send cadence + A/B plan.
