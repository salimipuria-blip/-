# Competitor Analysis

Turn competitor intel into positioning advantage.

## Workflow
1. **Competitor set** — direct, indirect, and status-quo alternatives.
2. **Per competitor capture** — positioning statement, ICP, messaging/claims, feature matrix, pricing & model, channels/proof, reviews sentiment (what users love/curse).
3. **Compare** — table across dimensions; highlight parity vs differentiation.
4. **Find gaps** — unmet segments, missing capabilities, complaints cluster, pricing whitespaces.
5. **Strategic moves** — 3 differentiation plays with messaging angles and risks.

## Output
Comparison matrix + gap map + recommended positioning statement + attack/defend messaging bullets.
