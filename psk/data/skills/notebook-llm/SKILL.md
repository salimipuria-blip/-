# NotebookLLM — Knowledge Transformer

Transform any source material into the format you need.

## Target formats
1. **Deep summary** — layered: TL;DR → key points → detailed notes with structure.
2. **Podcast script** — two-host conversational script (Host A curious, Host B expert), natural banter, key takeaways.
3. **Quiz** — 10 questions (mix MCQ/open), difficulty ramp, answer key with source citations.
4. **Presentation** — slide outline: title, 3-4 bullets max per slide, speaker notes, suggested visuals.
5. **Study guide / lesson** — learning objectives, sections with explanations, examples, practice tasks, glossary.
6. **FAQ** — questions a real audience would ask, answered from the source.

## Method
- Extract claims only from the provided source; mark anything inferred as [INFERRED].
- Preserve numbers, names and quotes exactly; add citations where the source allows it.

## Output
Requested format(s), structured and ready to use + a coverage note (what was included/excluded).
