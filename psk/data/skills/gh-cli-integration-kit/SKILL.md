# gh-cli-integration-kit

🗂 دسته: **کلاد کد (Claude Code)**
🎯 هدف این مهارت: کار با gh برای PR/Issue

## چه زمانی فعال شود
وقتی کاربر درخواستی مرتبط با «کار با gh برای PR/Issue» در حوزهٔ کلاد کد (Claude Code) بدهد؛ حتی اگر صریحاً نام مهارت را نگوید.
## گردش کار
1. نیاز را به یکی از این‌ها نسبت بده: skill / hook / MCP / subagent / slash command / CLAUDE.md.
2. پیکربندی را در مسیر درست بنویس (پروژه‌ای: .claude/ ، شخصی: ~/.claude/).
3. با یک سناریوی واقعی تست کن و لاگ نتیجه را ببین.
4. اختیارات را حداقلی کن (دایرکتوری‌ها/ابزارهای مجاز).
5. در CLAUDE.md یا README تیم ثبتش کن تا پایدار بماند.

## چک‌لیست کیفیت
- [ ] فایل‌ها در مسیر استاندارد با نام‌گذاری درست‌اند
- [ ] description برای تریگر خودکار بهینه است
- [ ] اختیارات محدود و امن است
- [ ] سناریوی تست موفق/ناموفق اجرا شد
- [ ] مستندات کوتاه فارسی/انگلیسی کنار فایل است

## خروجی
پیکربندی آماده + نحوهٔ فعال‌سازی + نمونهٔ استفاده.
