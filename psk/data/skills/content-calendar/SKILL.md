# Content Calendar

From pillars to a full publishing schedule.

## Method
1. **Inputs** — platforms, capacity (posts/week), 3-5 content pillars, key dates (launches, seasonal).
2. **Mix design** — balance: 40% value/education, 25% authority/proof, 20% personality/story, 15% offer.
3. **Grid** — per slot: date, platform, format, pillar, hook angle, asset needed, CTA, status.
4. **Briefs** — one-line brief per slot so any creator can execute.
5. **Buffers & loops** — evergreen reserve slots; weekly repurpose day; monthly review column.

## Output
Calendar table (2-4 weeks) + brief list + a simple Notion/Sheets-compatible CSV if requested.
