# Keyword Research

From seed topics to an intent-mapped content plan.

## Workflow
1. **Seeds** — gather seed terms from the product, audience pains, and competitor pages.
2. **Expand** — modifiers (how/what/best/vs/alternative/pricing/near me), long-tail questions, semantic variants.
3. **Classify intent** — informational / commercial / transactional / navigational; split mixed-intent SERPs.
4. **Score** — est. volume x business value / difficulty → opportunity score; flag quick wins (low DR ranking, forums on SERP).
5. **Cluster** — group into pillar + supporting pages; one URL per cluster; prevent cannibalization.
6. **Map** — keyword → URL (new or existing), funnel stage, content format.

## Output
Keyword table (term, cluster, intent, est. volume, difficulty, opportunity, target URL) + prioritized roadmap.
