# girih-pattern-generator

🗂 دسته: **طراحی (گرافیک و بصری)**
🎯 هدف این مهارت: تولید گیریه/گره‌چینی بردار

## چه زمانی فعال شود
وقتی کاربر درخواستی مرتبط با «تولید گیریه/گره‌چینی بردار» در حوزهٔ طراحی (گرافیک و بصری) بدهد؛ حتی اگر صریحاً نام مهارت را نگوید.
## گردش کار
1. بریف: پیام، مخاطب، رسانهٔ نهایی (پست/چاپ/بنر) و سایزها.
2. جهت بصری: سبک مرجع، گرید، تایپوگرافی (فارسی + لاتین)، پالت.
3. طراحی را بساز؛ سلسله‌مراتب و فضای خالی را جدی بگیر.
4. خروجی مناسب هر رسانه را استخراج کن (رنگ/فرمت/رزولوشن).
5. کنترل نهایی: bleed، DPI، نیم‌فاصله، خطای املایی.

## چک‌لیست کیفیت
- [ ] تایپوگرافی فارسی رعایت شده (نیم‌فاصله، نشانه‌گذاری)
- [ ] سلسله‌مراتب بصری واضح است
- [ ] رنگ/فونت با برند منطبق و دسترس‌پذیر (کنتراست)
- [ ] خروجی چاپی: CMYK/bleed/۳۰۰DPI کنترل شده
- [ ] فایل سورس مرتب و لایه‌ای تحویل می‌شود

## خروجی
فایل نهایی + مشخصات بصری (رنگ/فونت/سایز) + چک‌لیست چاپ/انتشار.
