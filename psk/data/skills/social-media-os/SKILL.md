# Social Media OS

Run the full loop: strategy → creation → publishing → analysis → growth.

## 1. Strategy
- Positioning: niche, audience, 3-5 content pillars, unique angle ("only I can say this because...").
- Cadence: weekly slots per format per platform.

## 2. Creation pipeline
- Idea capture → hook (see hook-generator rules) → body per platform-native format:
  posts, carousels, reels scripts, threads, thumbnails.
- Batching: one long-form asset → repurposed to 5-8 pieces (see content-repurposing).

## 3. Publishing
- Schedule plan (day/time hypotheses), platform checklists, first-comment strategy, reply templates.

## 4. Analysis (weekly)
- Metrics that matter per platform: watch time/retention, saves, shares, profile visits → follows.
- Pattern log: what format/topic/hook won and why.

## 5. Growth loop
- Double down on top-decile content; remix winners monthly; kill bottom formats.

## Output
Content plan (calendar + briefs) + ready assets + weekly scorecard template.
