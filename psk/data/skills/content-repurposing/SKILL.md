# Content Repurposing

1 asset in → 8-12 native pieces out.

## Method
1. **Mine the source** — extract: 1 core argument, 3-5 key insights, 5+ quotable lines, 1 story/anecdote, data points.
2. **Map to formats**:
   - X thread (argument spine) + 3 single posts (best quotes)
   - LinkedIn post (story angle, lesson format)
   - Carousel (insight per slide, 6-10 slides)
   - Reels script (strongest insight, see reels-scripting structure)
   - Newsletter intro/section
   - Community post (Reddit/Discord: genuine framing, no link drop)
3. **Native rewrite** — never copy-paste: match each platform's tone, length and first-line hook.
4. **Spacing plan** — schedule derivatives across 2 weeks; lead with strongest format.

## Output
Repurposing map table + all drafted pieces, labeled by platform, with publish order.
