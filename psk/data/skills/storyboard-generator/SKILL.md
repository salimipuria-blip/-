# Storyboard Generator

Script → shot list → visual panels.

## Method
1. **Beat breakdown** — split the script into narrative beats; total runtime target.
2. **Shot list** — per shot: #, duration, shot size (ECU/CU/MS/WS), angle/camera move (pan/dolly/static), subject+action, key dialogue/VO, on-screen text, transition.
3. **Visual panels** — optional: generate a panel per shot (image prompt per shot, consistent style/characters across prompts) in drawn-sketch style.
4. **Timing check** — V0 = script time budget per shot; flag shots < 1.5s (too fast to read) unless intentional.
5. **Sound map** — music mood, SFX moments, silence beats.

## Output
Shot-list table + (optional) panel image prompts/files + revised timing notes. Formats adapt: talking-head, product ad, explainer, cinematic.
