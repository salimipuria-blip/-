# agent-observability-tracing

🗂 دسته: **ایجنت‌ها / AI Agents**
🎯 هدف این مهارت: ردیابی و لاگ تصمیم‌های ایجنت

## چه زمانی فعال شود
وقتی کاربر درخواستی مرتبط با «ردیابی و لاگ تصمیم‌های ایجنت» در حوزهٔ ایجنت‌ها / AI Agents بدهد؛ حتی اگر صریحاً نام مهارت را نگوید.
## گردش کار
1. نقش ایجنت، مرز اختیار و تعریف «انجام شد» را مشخص کن.
2. ابزارها، دیتا و حافظهٔ لازم را فهرست و حداقلی نگه دار.
3. حلقهٔ اجرا را طراحی کن: دریافت کار → برنامه → اقدام → مشاهده → اصلاح.
4. گاردریل بگذار: برای اقدام حساس (پرداخت/حذف/انتشار) تأیید انسانی.
5. سناریوی تست بساز و رفتار موفق/شکست را اندازه بگیر.

## چک‌لیست کیفیت
- [ ] لاگ تصمیم‌ها و اقدام‌ها قابل بازبینی است
- [ ] برای عمل برگشت‌ناپذیر human-in-the-loop فعال است
- [ ] هزینهٔ توکن/زمان تحت کنترل است
- [ ] حالت fallback (شکست ابزار/آفلاین) تعریف شده
- [ ] خروجی نهایی برای کاربر فارسی و شفاف است

## خروجی
تعریف ایجنت (نقش/ابزار/سیاست‌ها) + جریان اجرا + مجموعهٔ تست.
