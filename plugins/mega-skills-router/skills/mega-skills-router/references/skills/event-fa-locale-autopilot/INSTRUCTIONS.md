# event-fa-locale-autopilot

🗂 دسته: **مهندسی پرامپت** — مشتق رابطه‌محور
🎯 هدف این مهارت: خلبان خودکار «fa-locale» برای حوزهٔ رویداد و همایش — کاربرد در دستهٔ مهندسی پرامپت

## چه زمانی فعال شود
وقتی کاربر درخواستی مرتبط با «خلبان خودکار «fa-locale» برای حوزهٔ رویداد و همایش — کاربرد در دستهٔ مهندسی پرامپت» بدهد؛ حتی بدون نام‌بردن مستقیم مهارت.
## گردش کار
1. «هدف» را یک‌جمله‌ای قفل کن: خلبان خودکار «fa-locale» برای حوزهٔ رویداد و همایش — کاربرد در دستهٔ مهندسی پرامپت
2. ورودی/زمینهٔ موجود را بخوان؛ در صورت نبود، نمونهٔ کوچک بساز.
3. مطابق قواعد دستهٔ «مهندسی پرامپت» اجرا کن و خروجی را آمادهٔ کپی تحویل بده.
4. فرض‌ها و محدودیت‌ها را صادقانه بنویس؛ مرحلهٔ بعدی را پیشنهاد بده.

## چک‌لیست کیفیت
- [ ] خروجی با هدف بخش اول هم‌خوان است
- [ ] استاندارد فارسی (نیم‌فاصله، تاریخ شمسی، تومان) رعایت شد
- فارسی/شمسی/تومان؛ خروجی آمادهٔ استفاده؛ فرض‌ها اعلام شود نه پنهان.

## خروجی
نتیجهٔ نهایی + چک‌لیست تأیید + پیشنهاد قدم بعدی.
