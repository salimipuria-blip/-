# Newsletter Writer

Issues people open and finish.

## Structure
1. **Subject line** — 30-50 chars; curiosity OR benefit; A/B pair (e.g. "The 3-line hook fix" vs "Why nobody reads past line 2"). Preview text extends, never repeats.
2. **Opener (first 3 lines)** — instant relevance: micro-story, bold stat, or reader problem; hook continues from subject.
3. **Main section** — one big idea per issue: story/lesson/framework with concrete takeaways; scannable subheads.
4. **Secondary blocks** — quick links (3 max, annotated), one quote/data point, reader question.
5. **Closer + single CTA** — reply prompt ("hit reply: what's your #1 struggle with X?") beats generic buttons.

## Rules
- Conversational 1:1 tone; write to one reader.
- Value first: selling ratio 1 promo per 4 pure-value issues.

## Output
Full issue text + 2 subject variants + send-time recommendation + engagement metric to watch.
