# iran-peaks-database-builder

🗂 دسته: **طبیعت‌گردی**
🎯 هدف این مهارت: پایگاه قله‌های ایران: ارتفاع/فصل/دشواری

## چه زمانی فعال شود
وقتی کاربر درخواستی مرتبط با «پایگاه قله‌های ایران: ارتفاع/فصل/دشواری» در حوزهٔ طبیعت‌گردی بدهد؛ حتی اگر صریحاً نام مهارت را نگوید.
## گردش کار
1. مشخصات: منطقه، فصل، سطح گروه، مدت، شروع/پایان.
2. مسیر: GPX/نقشهٔ آفلاین، آب‌رسانی، دشواری، پناه‌گاه‌ها.
3. تجهیز و تغذیه: لیست فصل‌محور، وزن، لایه‌بندی.
4. ایمنی فصول: سیلاب، بهمن، گرما، ارتفاع، حیات‌وحش — هر کدام با اقدام.
5. احترام: «ردی نگذار»، آداب روستا/عشایر, مجوز عکاسی از افراد.

## چک‌لیست کیفیت
- [ ] مسیر با نقشهٔ آفلاین و نقطهٔ بازگشت همراه است
- [ ] منابع آب/سایه/پناه‌گاه روی برنامه افتاده
- [ ] ریسک فصل با اقدام اولیه فارسی نوشته شده
- [ ] قواعد مناطق حفاظت‌شده و مجوزها بررسی شده
- [ ] برنامهٔ «اگر گم شدید» و تماس اضطراری دارد

## خروجی
راهنمای مسیر + چک‌لیست تجهیز + کارت ایمنی فصل.
