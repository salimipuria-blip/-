# brand-voice-builder

## هدف
ساخت یک سند کوتاه و عملیاتی از «صدای برند» که بعداً برای هر محتوایی (پست، ایمیل، پاسخ دایرکت) قابل استفاده باشد — نه یک مانیفست انتزاعی، بلکه ابزار کاری روزمره.

## چه زمانی فعال شود
وقتی کاربر دربارهٔ لحن برند، شخصیت برند، یکدست‌کردن محتوا، یا «چطور محتوامون یه‌جور به نظر برسه» صحبت می‌کند.

## گردش کار
1. **۳ صفت شخصیتی**: از کاربر بپرس یا از پیام‌هایش استنباط کن — برند اگر آدم بود چه‌جور آدمی بود؟ (مثلاً: صمیمی، متخصص، بی‌شوخی)
2. **طیف لحن**: روی یک محور مشخص کن — رسمی↔صمیمی، جدی↔شوخ‌طبع، ساده↔تخصصی. برای هر محور یک نقطه انتخاب کن، نه بازه مبهم.
3. **کلمات و عبارات**: لیست کوتاه «بگو» و «نگو» بساز (مثلاً: بگو «همراه شما هستیم»، نگو «بهترین در ایران»).
4. **نمونهٔ کاربردی**: همان پیام را با ۲ لحن متفاوت (برند فعلی در برابر یک لحن غلط رایج) بنویس تا تفاوت ملموس شود.
5. **تست سریع**: یک جملهٔ تصادفی از محتوای قبلی کاربر را بگیر و بگو آیا با این صدای برند هم‌خوان است یا نه، و چرا.

## چک‌لیست کیفیت
- [ ] صفات شخصیتی مبهم نیستند (نه «خوب» یا «حرفه‌ای» به‌تنهایی)
- [ ] حداقل ۳ نمونهٔ «بگو» و ۳ نمونهٔ «نگو» وجود دارد
- [ ] سند در یک صفحه خلاصه می‌شود، نه چند صفحه تئوری
- [ ] با نمونهٔ واقعی از محتوای کاربر تست شده

## خروجی
سند یک‌صفحه‌ای صدای برند (صفات + طیف لحن + بگو/نگو + نمونه) که مستقیم قابل استفاده در تولید محتواست.
