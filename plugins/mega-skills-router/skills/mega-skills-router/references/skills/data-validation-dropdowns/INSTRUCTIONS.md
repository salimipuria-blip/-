# data-validation-dropdowns

🗂 دسته: **اکسل (Excel)**
🎯 هدف این مهارت: لیست کشویی وابسته و اعتبارسنجی

## چه زمانی فعال شود
وقتی کاربر درخواستی مرتبط با «لیست کشویی وابسته و اعتبارسنجی» در حوزهٔ اکسل (Excel) بدهد؛ حتی اگر صریحاً نام مهارت را نگوید.
## گردش کار
1. ساختار دادهٔ ورودی و خروجی مطلوب را بفهم و یک نمونهٔ کوچک بساز.
2. شیت‌ها را طراحی کن: ورودی خام / محاسبات / گزارش.
3. فرمول‌ها یا اتوماسیون (Python/openpyxl) را بنویس و روی نمونه تست کن.
4. خطاهای رایج را فرض کن و با IFERROR/validation پوشش بده.
5. قالب‌بندی نهایی فارسی/راست‌چین و مناسب پرینت اعمال کن.

## چک‌لیست کیفیت
- [ ] تاریخ شمسی و اعداد فارسی/لاتین یکدست شده‌اند
- [ ] فرمول‌های کلیدی سند/توضیح دارند
- [ ] از رفرنس‌های شکننده (مستقیم/مطلق) درست استفاده شده
- [ ] قفل سلول‌های فرمولی پیشنهاد شده
- [ ] یک شیت «راهنما» کوتاه وجود دارد

## خروجی
فایل/کد + توضیح ساختار شیت‌ها + تست انجام‌شده.
