# cafe-critic-optimizer

🗂 دسته: **ایجنت‌ها** — مشتق رابطه‌محور
🎯 هدف این مهارت: بهینه‌ساز «critic» برای حوزهٔ کافه — کاربرد در دستهٔ ایجنت‌ها

## چه زمانی فعال شود
وقتی کاربر درخواستی مرتبط با «بهینه‌ساز «critic» برای حوزهٔ کافه — کاربرد در دستهٔ ایجنت‌ها» بدهد؛ حتی بدون نام‌بردن مستقیم مهارت.
## گردش کار
1. «هدف» را یک‌جمله‌ای قفل کن: بهینه‌ساز «critic» برای حوزهٔ کافه — کاربرد در دستهٔ ایجنت‌ها
2. ورودی/زمینهٔ موجود را بخوان؛ در صورت نبود، نمونهٔ کوچک بساز.
3. مطابق قواعد دستهٔ «ایجنت‌ها» اجرا کن و خروجی را آمادهٔ کپی تحویل بده.
4. فرض‌ها و محدودیت‌ها را صادقانه بنویس؛ مرحلهٔ بعدی را پیشنهاد بده.

## چک‌لیست کیفیت
- [ ] خروجی با هدف بخش اول هم‌خوان است
- [ ] استاندارد فارسی (نیم‌فاصله، تاریخ شمسی، تومان) رعایت شد
- فارسی/شمسی/تومان؛ خروجی آمادهٔ استفاده؛ فرض‌ها اعلام شود نه پنهان.

## خروجی
نتیجهٔ نهایی + چک‌لیست تأیید + پیشنهاد قدم بعدی.
