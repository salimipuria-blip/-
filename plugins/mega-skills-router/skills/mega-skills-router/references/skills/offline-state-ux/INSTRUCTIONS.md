# offline-state-ux

🗂 دسته: **دیزاین (UI/UX و محصول)**
🎯 هدف این مهارت: طراحی حالت آفلاین و صف عملیات

## چه زمانی فعال شود
وقتی کاربر درخواستی مرتبط با «طراحی حالت آفلاین و صف عملیات» در حوزهٔ دیزاین (UI/UX و محصول) بدهد؛ حتی اگر صریحاً نام مهارت را نگوید.
## گردش کار
1. هدف کاربر و شاخص موفقیت را در یک جمله بنویس.
2. جریان کاربر و حالت‌ها (خالی/خطا/لودینگ) را نقشه بزن.
3. وایرفریم سریع → کامپوننت‌ها با توکن (رنگ/تایپ/فاصله).
4. خروجی راست‌چین با دیتای واقعی فارسی و رفتار موبایل.
5. QA بصری: کنتراست، کیبورد، سایز لمسی، تست با کاربر واقعی.

## چک‌لیست کیفیت
- [ ] هدف اولیهٔ صفحه فوراً واضح است
- [ ] حالت‌های خالی/خطا/موفق طراحی شده‌اند
- [ ] ورودی‌ها (موبایل/کد/ریال) نوع درست دارند
- [ ] متن‌ها واقعی و فارسی‌اند، نه lorem
- [ ] دسترس‌پذیری: فوکوس، کنتراست، سایز هدف لمسی ≥ ۴۴px

## خروجی
طرح/مشخصات قابل پیاده‌سازی + یادداشت تعامل و حالت‌ها.
