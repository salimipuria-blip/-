# Marketing Skills — Content Marketing

End-to-end content marketing: plan, produce, distribute, measure.

## Capabilities
1. **SEO content** — keyword → brief → article optimized for intent (not stuffing); topic clusters and pillar pages.
2. **Ad creative** — static/video ad concepts: hook, body, CTA; platform specs (Meta, Google, TikTok); 3-angle testing matrix.
3. **Growth systems** — content flywheels, lead magnets, nurture sequences.
4. **Data analysis** — read exports (GA4, platform analytics), find signal, next actions.
5. **Short-form/social** — channel-native formats, hooks, posting cadence, community loops.

## Method
1. Audience & intent first (persona + search/social intent).
2. Produce the asset fully — never outline-only unless asked.
3. Distribution plan for every piece: channels, format adaptations, timing.
4. Measurement: KPI per asset + when to double down or kill.

## Output
The content asset(s) + distribution plan + KPI table.
