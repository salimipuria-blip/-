# WhatsApp Sales Script FA — اسکریپت فروش پیام‌رسانی

## الگوی گفتگو (۶ مرحله)
1. **بازکردن گرم (≤ ۲ خط):** سلام + منشا («از اینستا پیام دادید؟ 😊») — سؤالِ «قیمت؟» نیفت تا مقدمه ساختی.
2. **شناخت سریع (فقط ۲ سؤال):** تعداد نفر + تاریخ مدنظر. ترکیب در یک پیام با گزینه («آخر هفته پیشنهاد داریم: الف … ب …»).
3. **پیشنهاد با ارزش (۱ پیام):** نام تور + یک مزیت احساسی + یک واقعیت عددی (مدت/ظرفیت/شامل‌ها) — حجم کم، خوانا.
4. **قیمت‌گذاری (شفاف):** قیمت نفر + «شامل X/Y» در ۲ خط + گزینهٔ دوم متمایز (دوروزه/خصوصی) تا مقایسه کند.
5. **رفع اعتراض (بانک پایین)** و **بستن:** پیشنهاد قدم کوچک: ثبت با ودیعهٔ X تومان + «ظرفیت رسمی ۱۲ نفر، ۵ جا مونده» (فقط اگر درسته).
6. **پیگیری:** ۲۴ ساعت بعد (نرم) و ۷۲ ساعت بعد (آخر)؛ بعد از آن «در آینده خبر می‌دم» و تمام.

## بانک پاسخ اعتراض (فارسی کوتاه)
- **«گرانه»** → ارزش را بشکن: «سرشکن نفری X که شامل ترانسفر/لیدر/بیمه‌ست؛ گزینهٔ یک‌روزه هم هست Y»
- **«فکر می‌کنم»** → بدون فشار + انگیزهٔ تصمیم: «حتماً؛ تا فردا این قیمت/ظرفیت ثابته، پس فردا ممکنه تکمیل بشه»
- **«باید با ... مشورت کنم»** → فرستادن خلاصهٔ فورواردشوندهٔ ۳خطی برای همان فرد.
- **«تاریخ نمی‌خوره»** → لیست دفعات بعد + «خبر اول برای شما (opt-in)»

## قواعد پیام‌رسانی
- هر پیام ≤ ۴ خط؛ پاراگراف با ایموجی کمتر = خواناتر.
- ادب ایرانی بدون تعارف زیاد: «در خدمتم» یک‌بار کافیست.
- فایل/تیزر فقط بعد از ابراز علاقه؛ نام فایل معنادار (Tour_Maranjab_Azar.pdf).
- حریم: شماره مشتری را در گروه/فوروارد لو نده.
- نه فلود: max ۲ پیام بدون پاسخ؛ بعد توقف.

## خروجی
1. نسخهٔ آمادهٔ کپی ۶ مرحله با placeholder ({تور}، {قیمت}، {تاریخ})
2. ۳ سی‌تی‌ای جایگزین (رزرو/مشاوره/بمان برای دفعهٔ بعد)
3. متن‌های پیگیری ۲۴ و ۷۲ ساعته
4. چک‌لیست «قبل از ارسال»: اسم/تور/تاریخ/عدد درست؟ لینک پرداخت تست‌شده؟
