# agent-decision-tracing

🗂 دسته: **زیرساخت عامل** — از لایهٔ عمومی جهان
🎯 هدف این مهارت: ردگیری تصمیم‌ها و علت انتخاب‌ها

## چه زمانی فعال شود
وقتی کاربر درخواستی مرتبط با «ردگیری تصمیم‌ها و علت انتخاب‌ها» بدهد؛ حتی بدون نام‌بردن مستقیم مهارت.
## گردش کار
1. «هدف» را یک‌جمله‌ای قفل کن: ردگیری تصمیم‌ها و علت انتخاب‌ها
2. ورودی/زمینهٔ موجود را بخوان؛ در صورت نبود، نمونهٔ کوچک بساز.
3. مطابق قواعد دستهٔ «زیرساخت عامل» اجرا کن و خروجی را آمادهٔ کپی تحویل بده.
4. فرض‌ها و محدودیت‌ها را صادقانه بنویس؛ مرحلهٔ بعدی را پیشنهاد بده.

## چک‌لیست کیفیت
- [ ] خروجی با هدف بخش اول هم‌خوان است
- [ ] استاندارد فارسی (نیم‌فاصله، تاریخ شمسی، تومان) رعایت شد
- فارسی/شمسی/تومان؛ خروجی آمادهٔ استفاده؛ فرض‌ها اعلام شود نه پنهان.

## خروجی
نتیجهٔ نهایی + چک‌لیست تأیید + پیشنهاد قدم بعدی.
