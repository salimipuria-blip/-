# private-vip-tour-builder

🗂 دسته: **تور (Tour)**
🎯 هدف این مهارت: طراحی تور خصوصی/وی‌آی‌پی

## چه زمانی فعال شود
وقتی کاربر درخواستی مرتبط با «طراحی تور خصوصی/وی‌آی‌پی» در حوزهٔ تور (Tour) بدهد؛ حتی اگر صریحاً نام مهارت را نگوید.
## گردش کار
1. مشخصات: مقصد، فصل، تعداد نفر، بودجه، سطح سختی.
2. مسیر روزبه‌روز با فاصله/زمان و توقف‌های واقعی بنویس.
3. لجستیک: حمل‌ونقل (قطار/اتوبوس/پرواز/مینی‌بوس)، اقامت، وعده‌ها.
4. مالی: قیمت سرشکن به تومان، ودیعه/تسویه، سیاست کنسلی.
5. اسناد فروش/اطلاع‌رسانی: فرمت فراخوان، لندینگ، پیام گروه.

## چک‌لیست کیفیت
- [ ] تاریخ‌ها شمسی و ساعت‌ها طبق واقعیت جاده‌ای‌اند
- [ ] پلن B برای هر روز هوایی/مسیر دارد
- [ ] مجوزها/راهنما/راننده مشخص است
- [ ] سطح سختی و تجهیزات لازم شفاف اعلام شده
- [ ] اطلاعات تماس و تجمع کامل است

## خروجی
برنامهٔ کامل تور + جدول هزینه + متن اطلاع‌رسانی به نفرات.
