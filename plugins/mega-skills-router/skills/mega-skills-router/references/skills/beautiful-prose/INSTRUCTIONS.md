# Beautiful Prose

Craft prose people remember: smooth, precise, alive.

## Principles
1. **Cut filler** — delete "very, really, just, actually, basically"; if a sentence adds nothing, cut it.
2. **Specifics over abstractions** — show the concrete (numbers, objects, scenes); let readers conclude.
3. **Rhythm** — mix short and long sentences; use parallel structure sparingly; end paragraphs on the strongest word.
4. **Fresh imagery** — ban clichés ("needle in a haystack"); earn metaphors from the subject's own domain.
5. **Active voice** — default; passive only when the actor is irrelevant.
6. **No AI patterns** — no triads-of-adjectives, no "not only X but also Y" chains, no summary-starters.

## Method
1. Understand audience & goal of the piece.
2. Draft or rewrite fully; then a separate edit pass: tighten 10-20%.
3. Final read-aloud check for flow.

## Output
The finished text + a brief editor's note on key choices.
