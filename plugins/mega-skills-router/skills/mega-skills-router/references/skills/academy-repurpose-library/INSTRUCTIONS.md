# academy-repurpose-library

🗂 دسته: **تولید محتوا** — مشتق رابطه‌محور
🎯 هدف این مهارت: کتابخانهٔ آمادهٔ «repurpose» برای حوزهٔ آکادمی آنلاین — کاربرد در دستهٔ تولید محتوا

## چه زمانی فعال شود
وقتی کاربر درخواستی مرتبط با «کتابخانهٔ آمادهٔ «repurpose» برای حوزهٔ آکادمی آنلاین — کاربرد در دستهٔ تولید محتوا» بدهد؛ حتی بدون نام‌بردن مستقیم مهارت.
## گردش کار
1. «هدف» را یک‌جمله‌ای قفل کن: کتابخانهٔ آمادهٔ «repurpose» برای حوزهٔ آکادمی آنلاین — کاربرد در دستهٔ تولید محتوا
2. ورودی/زمینهٔ موجود را بخوان؛ در صورت نبود، نمونهٔ کوچک بساز.
3. مطابق قواعد دستهٔ «تولید محتوا» اجرا کن و خروجی را آمادهٔ کپی تحویل بده.
4. فرض‌ها و محدودیت‌ها را صادقانه بنویس؛ مرحلهٔ بعدی را پیشنهاد بده.

## چک‌لیست کیفیت
- [ ] خروجی با هدف بخش اول هم‌خوان است
- [ ] استاندارد فارسی (نیم‌فاصله، تاریخ شمسی، تومان) رعایت شد
- فارسی/شمسی/تومان؛ خروجی آمادهٔ استفاده؛ فرض‌ها اعلام شود نه پنهان.

## خروجی
نتیجهٔ نهایی + چک‌لیست تأیید + پیشنهاد قدم بعدی.
