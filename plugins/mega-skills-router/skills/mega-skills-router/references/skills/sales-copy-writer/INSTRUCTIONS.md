# sales-copy-writer

## هدف
نوشتن متنی که مشتری بالقوه را از «آگاهی» به «اقدام» (خرید، تماس، رزرو) می‌رساند — با تمرکز روی نیاز واقعی مشتری، نه فقط تعریف از محصول.

## چه زمانی فعال شود
وقتی کاربر می‌خواهد: متن صفحهٔ فروش، پاسخ به پیام مشتری مردد، پیگیری فروش، پاسخ به اعتراض قیمت، یا متن تبلیغاتی بنویسد.

## گردش کار
1. **مشکل مشتری، نه ویژگی محصول**: اول مشخص کن مشتری چه دردی دارد که این محصول/خدمت حلش می‌کند — از آنجا شروع کن، نه از لیست ویژگی‌ها.
2. **ساختار AIDA کاربردی**:
   - توجه: یک جملهٔ اول که دقیقاً حرف دل مشتری را می‌زند.
   - علاقه: چرا این راه‌حل با بقیه فرق دارد (تمایز واقعی، نه شعار).
   - تمایل: نتیجهٔ ملموس/داستان واقعی/عدد — نه ادعای کلی.
   - اقدام: یک درخواست مشخص و کم‌اصطکاک (نه «همین حالا خرید کن» بدون زمینه).
3. **مدیریت اعتراض رایج**: اگر موضوع قیمت، اعتماد، یا زمان‌بندی است، یک پاسخ صادقانه و نه تدافعی برایش بنویس.
4. **صداقت**: هیچ ادعایی که کاربر تأیید نکرده اضافه نکن؛ اگر آماری لازم است، از کاربر بخواه یا علامت‌گذاری کن که جای‌گذاری‌شدنی است.

## چک‌لیست کیفیت
- [ ] متن با مشکل مشتری شروع می‌شود، نه با «ما»
- [ ] هیچ ادعای غیرقابل‌اثبات یا اغراق‌شده ندارد
- [ ] یک درخواست اقدام مشخص دارد
- [ ] لحن فشار روانی مصنوعی (FOMO کاذب) ندارد مگر واقعی باشد
- [ ] برای مخاطب هدف قابل‌فهم است، نه پر از عبارت تخصصی بی‌مورد

## خروجی
متن فروش نهایی + یک نسخهٔ کوتاه‌تر برای پیام مستقیم (دایرکت/واتساپ) از همان پیام.
