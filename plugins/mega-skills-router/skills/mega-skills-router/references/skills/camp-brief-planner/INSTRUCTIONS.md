# camp-brief-planner

🗂 دسته: **درک صحیح** — مشتق رابطه‌محور
🎯 هدف این مهارت: برنامه‌ریز «brief» برای حوزهٔ کمپ — کاربرد در دستهٔ درک صحیح

## چه زمانی فعال شود
وقتی کاربر درخواستی مرتبط با «برنامه‌ریز «brief» برای حوزهٔ کمپ — کاربرد در دستهٔ درک صحیح» بدهد؛ حتی بدون نام‌بردن مستقیم مهارت.
## گردش کار
1. «هدف» را یک‌جمله‌ای قفل کن: برنامه‌ریز «brief» برای حوزهٔ کمپ — کاربرد در دستهٔ درک صحیح
2. ورودی/زمینهٔ موجود را بخوان؛ در صورت نبود، نمونهٔ کوچک بساز.
3. مطابق قواعد دستهٔ «درک صحیح» اجرا کن و خروجی را آمادهٔ کپی تحویل بده.
4. فرض‌ها و محدودیت‌ها را صادقانه بنویس؛ مرحلهٔ بعدی را پیشنهاد بده.

## چک‌لیست کیفیت
- [ ] خروجی با هدف بخش اول هم‌خوان است
- [ ] استاندارد فارسی (نیم‌فاصله، تاریخ شمسی، تومان) رعایت شد
- فارسی/شمسی/تومان؛ خروجی آمادهٔ استفاده؛ فرض‌ها اعلام شود نه پنهان.

## خروجی
نتیجهٔ نهایی + چک‌لیست تأیید + پیشنهاد قدم بعدی.
