# Meeting Summarizer

Transcript → decisions and actions people actually read.

## Extraction
1. **Decisions** — what was decided, final wording, who decided.
2. **Action items** — task, owner, due date (mark missing owner/date as TBD).
3. **Open questions / parked topics**.
4. **Risks & blockers** mentioned.
5. **Highlights** — key metrics, quotes, announcements.

## Rules
- No chronological recap of "who said what"; group by theme.
- Flag unresolved conflicts explicitly.
- Keep the summary scannable: table for actions, bullets rest.

## Output
TL;DR (2-3 lines) + decisions list + actions table + open questions + risks.
