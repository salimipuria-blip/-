# Podcast Producer

Everything around an episode except the audio file itself.

## Deliverables
1. **Episode outline** — cold open hook, 3-5 segments, arcs, per-segment beats, closing CTA.
2. **Script** — intro/outro verbatim + segment talking points (not overwritten: keep host natural).
3. **Chapters** — timestamps plan with titles (benefit-worded, not "Segment 3").
4. **Show notes** — 100-200 word summary, key takeaways, links, guest bio.
5. **Titles** — 10 options: curiosity vs clarity balance, guest-name leverage, < 60 chars.
6. **Promotion kit** — 3 quote snippets, audiogram caption, 1 thread/post per platform.

## Rules
- Define listener + one takeaway promise before outlining.
- Every segment must earn its place (cut e filler).

## Output
Episode pack file(s) with all the above, publication-ready.
